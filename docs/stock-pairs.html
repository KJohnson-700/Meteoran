Data quality. A large fraction of the raw /pools pull is structurally corrupt — TVL of 3e-12, APR of 6e13. Every figure on this page is post-filter. A single unfiltered row sorts an entire table, which is why every public leaderboard on this venue is untrustworthy.

What this is not

Not a strategy, not a bot, not a ranking product. It is a pool-level cross-section from one pull: no wallet-level skill measurement, no time series, no persistence test. A first measurement with a direction.
